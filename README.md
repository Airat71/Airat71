### 🔧 Системное администрирование

🔹 **[Linux Admin Toolkit](https://github.com/Airat71/linux-admin-toolkit)**  
Коллекция полезных скриптов для ежедневных задач системного администратора: мониторинг, бэкапы, безопасность, автоматизация.

🔹 **[Server Monitoring Dashboard](https://github.com/Airat71/server-monitoring)**  
Легковесная система мониторинга серверов с веб-интерфейсом. Отслеживание CPU, RAM, Disk, Network в реальном времени.

🔹 **[Docker Production Stacks](https://github.com/Airat71/docker-production-stacks)**  
Готовые docker-compose стеки для быстрого развертывания: LEMP, LAMP, Node.js, WordPress, и другие.

🔹 **[Nginx Config Library](https://github.com/Airat71/nginx-config-library)**  
Библиотека настроенных конфигураций Nginx для различных задач: reverse proxy, load balancing, SSL/TLS, кэширование.

🔹 **[Automated Backup System](https://github.com/Airat71/automated-backup-system)**  
Система автоматического резервного копирования с ротацией, сжатием, удаленным хранением и уведомлениями.
